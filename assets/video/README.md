# Ролики

Сюда кладутся видео для блоков, где сейчас стоит постер из макета.

- Имя файла = id блока: `assets/video/<id>.mp4` (или `.webm`).
  Список id и что уже заполнено — `python3 tools/videos.py`.
- Не хотим класть файл в публичный репозиторий — вместо него строка
  в `links.json`: `{"<id>": "https://.../clip.mp4"}` (прямая ссылка на файл,
  не на страницу плеера).
- После добавления — `python3 tools/build.py` и `bash tools/publish.sh`.

Формат: H.264 mp4, звук AAC, ширина 1280 (широкий блок в интро) или 640
(превью форматов в ряду по три). Ориентир по весу — до 3–5 МБ на ролик:
GitHub не принимает файлы тяжелее 100 МБ, а Pages отдаёт до 1 ГБ на сайт.

Постер остаётся картинкой из макета и грузится всегда, само видео — только
после клика (`preload="none"`).
