# Лендинг форматов

Гайды по рекламным форматам Кинопоиска. Статический сайт, собран из макета Figma
[«Лендинг форматов»](https://www.figma.com/design/uYLX67r8VhmLg0TGH5Izrg) — страница `Alina`,
узлы `469:17008` (Преролл) и `469:17400` (Баннер).

## Страницы

- `index.html` — Преролл
- `banner.html` — Баннер

## Темы

Тёмная — та, что в макете. Светлая собрана зеркально по той же шкале прозрачностей:
в коллекции `Theme` файла Figma светлого режима нет, поэтому значения выведены, а не
скопированы. Акцент `#FF5500` общий для обеих.

**По умолчанию тёмная** — системная настройка её не переопределяет. Светлая включается
только вручную переключателем внизу навигации, выбор запоминается (`localStorage`,
ключ `theme`).

Правки цветов — в блоках `:root` / `[data-theme="light"]` в `assets/css/style.css`,
остальная вёрстка ходит только через токены и про темы ничего не знает.

## Как устроено

Чистый HTML + CSS, без сборки и зависимостей в рантайме. Открывается двойным кликом,
кладётся на любой статический хостинг как есть.

```
assets/css/style.css   токены и вёрстка
assets/js/app.js       мобильное меню, подсветка активного пункта оглавления
assets/img/            иллюстрации, выгруженные из Figma (webp)
tools/                 скрипты пересборки из макета
```

## Как включиться в работу

```bash
git clone https://github.com/milomay/landing-formats.git
cd landing-formats
python3 -m http.server 4173   # открыть http://localhost:4173
```

Ставить больше нечего: сборки нет, зависимостей в рантайме нет. `.refs/content.json`
лежит в репозитории, поэтому `python3 tools/build.py` работает сразу после клонирования —
токен Figma нужен только тому, кто меняет сам макет и запускает `tools/extract.py`.

Чего в репозитории нет и не будет: лицензионные шрифты (`fonts/`) и исходники роликов
(`assets/video/<слот>/`). Оба пункта намеренные, подробности в разделах ниже. Без шрифтов
сайт открывается на фолбэках — макет один в один увидит тот, у кого они стоят на машине.

Права на пуш выдаются в Settings → Collaborators репозитория, доступ к макету — отдельно
в Figma. Выкатывает изменения на сайт `bash tools/publish.sh`.

## Пересобрать из макета

Нужен `FIGMA_TOKEN` в окружении и Pillow (`pip install pillow`).

```bash
curl -s "https://api.figma.com/v1/files/uYLX67r8VhmLg0TGH5Izrg/nodes?ids=469:17008,469:17400" \
  -H "X-Figma-Token: $FIGMA_TOKEN" -o .refs/full.json
python3 tools/extract.py       # макет → .refs/content.json
python3 tools/fetch_images.py  # рендер картинок в assets/img (webp, дубли склеиваются)
python3 tools/build.py         # content.json → index.html, banner.html
```

Правки контента делаются в макете и приезжают через пересборку — руками HTML не правим,
иначе следующая сборка их затрёт.

## Локальный просмотр

```bash
python3 -m http.server 4173
```

## Публикация

```bash
gh auth login          # один раз
bash tools/publish.sh  # создаёт публичный репозиторий и включает GitHub Pages
```

Скрипт идемпотентный: повторный запуск просто пушит изменения. Имя репозитория можно
задать аргументом — `bash tools/publish.sh my-repo`.

## Шрифты

В макете — `Graphik Kinopoisk LC` и `SangBleu Sunrise`. Оба коммерческие, поэтому
**в репозиторий не попадают** (`fonts/` и `assets/fonts/` в `.gitignore`): выкладывать их
файлы в открытый доступ лицензия не разрешает.

Порядок в `--font` / `--font-display`: сначала фирменные — у кого они установлены на машине,
видит макет один в один; дальше открытые аналоги с Google Fonts, `Inter` для текста
и `Playfair Display` для крупных заголовков.

Если сайт когда-нибудь переедет в закрытый контур, где отдавать шрифты можно, всё готово:
положить исходники в `fonts/`, выполнить `python3 tools/fonts.py` (соберёт woff2 нужных
начертаний в `assets/fonts/`) и подключить `assets/css/fonts.css` в шаблоне `tools/build.py`
вместо ссылки на Google Fonts. Сейчас `fonts.css` намеренно не подключён.
